When · If · Then

Desk orchestration is When · If · Then. Sequential is one rule after another. Conditional is If. Human in the loop is Yes / Stop / Kill. Map those words to this desk. Not a Router Node. Not a mesh of Desk AIs. Not a node canvas.

Drop. Connection event. Inbound name@account.aia. Status change.
