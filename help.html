When · If · Then

Desk language. One line on this desk, or a pack that strings them.

When · Trigger
Drop. Pipe event. Inbound name@account.aia. Status change.
If · Condition
Rules / Qualify check. Tag, word on the card, unassigned, older than, money, field.
Then · Action
Desk AI drafts. Queue card. Notify. Human Yes / Stop for outbound or money. Collect stays HOLD.
Rule
One When → If → Then on this desk. Fresh desks start empty. Add a wait only if you want one.
Workflow / Sequence
A pack that strings rules. Optional delay or branch. Still thin JSON. No dashboard fork. Write it in Creators Studio.
